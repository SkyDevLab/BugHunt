# Contributing to BugHunt AI

Thank you for your interest in contributing to **BugHunt AI**, the autonomous ticket-to-bug QA agent plugin for Google Antigravity.

## Code of Conduct & Core Values

1. **Evidence Integrity**: Never fabricate test results, simulated logs, or artificial screenshot evidence. Every finding must stem from reproducible DOM assertions.
2. **Safety & URL Scoping**: Strict boundary enforcement is required. Never bypass URL origin checks or permit unvetted navigation.
3. **Reproducibility**: Candidate defects must undergo multi-pass reproduction before classification.

---

## Development Setup

### Prerequisites
- **Node.js**: >= 18.0.0 (Node 20+ recommended)
- **Playwright Chromium**: installed via `npx playwright install chromium`
- **Git**

### Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/SkyDevLab/BugHunt.git
cd BugHunt
npm install
```

---

## Running Tests

Run unit tests:
```bash
npm run test:unit
```

Run end-to-end browser tests:
```bash
npm run test:e2e
```

Run the full automated test suite:
```bash
npm test
```

Run the complete live demonstration against the local fixture app:
```bash
npm run demo
```

---

## Adding New Test Scenarios

Test scenarios are generated by `src/test-planner.js` and executed by `src/browser-explorer.js`.

When introducing new scenario types:
1. Define the scenario schema in `src/test-planner.js` with `testType`, `category`, and actionable `steps`.
2. Implement the observable DOM assertion in `src/browser-explorer.js`.
3. Capture full-page screenshot evidence *before* altering or resetting the browser state.
4. Add unit test coverage in `tests/test-planner.test.js` and integration tests in `tests/e2e-demo.test.js`.

---

## Submitting Pull Requests

1. Create a feature branch: `git checkout -b feature/your-feature-name`
2. Ensure all 26+ automated tests pass with `npm test`.
3. Verify the end-to-end demo passes with `npm run demo`.
4. Commit your changes: `git commit -m "feat: add support for modal dialog validation"`
5. Push to your fork and submit a Pull Request to `SkyDevLab/BugHunt`.
